# J.A.R.V.I.S. — 웹 버전

홀로그램 HUD 개인 AI 비서. 폰 크롬에서 바로 열립니다.

**▶ 열기:** https://raw.githack.com/sunwoobaek15-sys/jarvis-model1/main/index.html

## 처음 쓸 때
1. 위 링크를 **크롬**에서 엽니다.
2. 오른쪽 위 **CONFIG** → **ANTHROPIC API KEY** 에 키(`sk-ant-...`)를 넣고 **DONE**.
   키는 그 브라우저에만 저장되고 Anthropic 서버로만 전송됩니다.
3. 가운데 코어를 탭 → 마이크 허용 → 말하기.

## 기능
대화(한국어 음성 답변), 메모, 할 일, 리마인더, 타이머. 리마인더와 타이머는 이 화면이 열려 있을 때만 울립니다.

원본 소스와 안드로이드 앱: 비공개 레포 `clasecodecase` 의 `jarvis-web/`, `jarvis-android/`.
